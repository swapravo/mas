# Download my data

**Agents:** Frontend, Backend, Security

Add a "Download my data" button on the profile page. Users want a copy of everything we hold on them: profile, addresses, orders and support chats. The orders table has about 3 million rows, and some power users have 2,000+ orders. Our API host cuts any request at 30 seconds. Exported files would be stored in the same cloud bucket as our product images. Support chats include messages written by our staff. About 20% of our users are in the EU.
